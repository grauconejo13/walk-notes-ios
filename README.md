# Walk Notes

Walk Notes is a free iPhone photo journal for details you notice on a walk. Save a photo, write a short note about what made you stop, and optionally give the place a name.

## First milestone

- [ ] Create a SwiftUI app with a journal that shows the newest entries first.
- [ ] Add an entry with one photo from the photo library, a short note, and an optional place name.
- [ ] Store entries and their photos on the device so the journal works offline and survives relaunches.
- [ ] Include a clearly labeled Budapest sample entry. Personal entries can be from anywhere.
- [ ] Verify the flow in the iPhone simulator and document how to run it.

The first milestone is complete when you can save an entry, reopen the app offline, and see the photo and note in the journal.
